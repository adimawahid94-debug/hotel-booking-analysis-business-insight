🏨 Hotel Booking Cancellation & Revenue Optimization
📌 Project Overview
Proyek ini bertujuan untuk mengatasi masalah pembatalan reservasi hotel yang mencapai 37%. Dengan menggunakan analisis prediktif, proyek ini berhasil mengidentifikasi potensi penyelamatan pendapatan sebesar $2.1M - $2.5M.

📊 Business Problems
High Cancellation Rate: >30% reservasi dibatalkan.

Revenue Loss: Estimasi kerugian mencapai $12.7 Juta.

Inventory Management: Kamar kosong yang tidak terisi kembali.

🛠️ Tech Stack
Language: Python (Pandas, NumPy, Matplotlib, Seaborn)

Tool: Jupyter Notebook

💡 Key Insights & Solutions
Insight: Lead time tinggi dan kebijakan No Deposit adalah pemicu utama pembatalan.

Solution: Implementasi kebijakan deposit berjenjang 25% dan strategi overbooking 10%.
